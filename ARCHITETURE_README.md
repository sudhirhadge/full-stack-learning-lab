## Project Summary

This repository is a **full-stack learning lab** focused on experimenting with modern frontend and backend stack patterns.

### What it contains

- README.md
  - Describes the repository as a living full-stack playground for learning React, Next.js, TypeScript, and modern frontend/backend best practices.
- client
  - A Next.js project using:
    - `next` `16.2.4`
    - `react` `19.2.4`
    - `typescript`
    - `Tailwind CSS v4`
  - Includes development scripts like:
    - `npm run dev`
    - `npm run build`
    - `npm run start`
    - `npm run lint`
- server.js
  - Contains a placeholder README.md indicating server-side development is planned but not implemented yet.

### Purpose

This project is primarily a **learning and experimentation workspace**, where each change is intended to capture a new concept or technique in full-stack development.

### Current state

- Frontend is scaffolded and ready as a Next.js app.
- Backend is currently only noted as a future development area.
